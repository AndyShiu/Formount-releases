隱私權政策

最後更新:2026 年 10 月 1 日
Formount 不收集、不上傳任何個人資料或檔案內容,也沒有帳號系統。

我們收集的資料

Formount 不收集、不上傳任何個人資料或檔案內容;沒有帳號系統。

登入資料的儲存

儲存空間的登入資料(密碼、存取金鑰、OAuth token)只存在你 Mac 上的加密設定檔與鑰匙圈。

與儲存服務的連線

Formount 直接連到你自己設定的儲存服務。使用 Google 雲端硬碟、OneDrive、Dropbox 時,只用來列出、讀取、寫入你在 Finder 中操作的檔案。

Google API 服務使用者資料政策

Formount 對 Google 使用者資料的使用與轉移,遵守 Google API Services User Data Policy,包括「有限使用」(Limited Use)的規定。

檢查更新

檢查更新時會連到 GitHub 下載更新資訊,只包含 App 版本,不含個人資料。

聯絡方式

對這份政策有任何問題,請到 GitHub 開議題: Formount 議題回報
